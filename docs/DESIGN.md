# ZERO ZONE — проектный документ (Этап 1)

> Живой документ. Отражает текущие решения; помечено, что уже реализовано (✅), что упрощено (🟡) и что запланировано (⏳).

---

## 1. Анализ задания

Задание описывает открытый мир масштаба AA‑проекта (6 крупных локаций, NPC с распорядком, транспорт, строительство). Реалистичная стратегия — **вертикальный срез**: одна полностью рабочая локация, в которой связаны *все* основные системы, плюс архитектура, позволяющая добавлять локации данными и модулями, не переписывая ядро.

Ключевые риски и ответы на них:

| Риск | Решение |
|---|---|
| Производительность Android | Mobile‑рендерер (Vulkan) с автоматическим откатом на OpenGL ES 3; бюджет: ≤ 150 draw calls в кадре, ≤ 300k треугольников; MultiMesh для растительности; visibility range (HLOD) для пропсов; occlusion culling для зданий. |
| Размер APK | Процедурная геометрия зданий + переиспользуемые CC0‑текстуры 1K со сжатием ETC2/ASTC; процедурно синтезируемый эмбиент (ветер, дождь, гул) вместо гигабайт аудио. |
| «Красивое меню и пустая сцена» | Каждая кнопка вызывает реальную систему; все системы сохраняются; проверка headless‑тестами в CI. |
| Сборка без редактора | Мир собирается кодом из данных (детерминированно по seed) — проект собирается в CI одной командой. |
| Лицензии | Только CC0 (Poly Haven, Kenney) или собственные процедурные ассеты; каталог в `docs/ASSETS.md`. |

## 2. Выбор технологий

### 2.1 Движок

| Критерий | **Godot 4.7** | Unity 6 | Unreal 5 | Babylon/Three + WebView |
|---|---|---|---|---|
| Лицензия | MIT, без отчислений | Подписка/условия рантайма | 5 % роялти | MIT |
| Сборка APK в CI | Одна headless‑команда, без активации | Нужна лицензия в секретах CI | Тяжёлый тулчейн, часы сборки | Просто, но WebView‑3D медленный |
| Пустой APK | ~30 МБ | ~25–40 МБ | 100+ МБ | ~5 МБ + ассеты |
| Мобильный 3D | Mobile‑рендерер Vulkan + GLES3 | Отлично (URP) | Тяжело для бюджетных Android | Слабо |
| Порт на PC | Тот же проект, экспорт Win/Linux/macOS | Да | Да | Через Electron |
| Скорость итераций | GDScript, мгновенный запуск | C#, компиляция | C++/Blueprints, медленно | Быстро |

**Выбор: Godot 4.7.2 (stable).** Решающие факторы — полностью открытая сборка в GitHub Actions без лицензий, малый размер, единый проект для Android и PC, достаточный для мобильного 3D рендерер. Unity сильнее по экосистеме ассетов, но требует лицензионной активации в CI и привязывает проект к условиям вендора.

### 2.2 Язык
**GDScript со статической типизацией.** Быстрая разработка, нулевой оверхед на сборку, нативная интеграция с движком. Узкие места (если появятся — например, массовый ИИ толпы) выносятся в GDExtension на C++ без изменения архитектуры. C# отвергнут: +~20 МБ к APK из‑за .NET и менее зрелый экспорт на Android.

### 2.3 Остальной стек

| Задача | Решение | Почему |
|---|---|---|
| Рендер | Mobile (Vulkan), fallback GL Compatibility | Лучшее качество на Android при сохранении совместимости со старыми GPU |
| Модели | glTF 2.0 (`.glb`) | Открытый стандарт, нативный импорт Godot, PBR |
| Текстуры | JPG/PNG в репо → VRAM‑сжатие ETC2/ASTC (Android), S3TC/BPTC (PC) | Маленький репозиторий, оптимальная видеопамять |
| Данные игры | JSON в `data/` (предметы, рецепты, лут, диалоги, записки, квесты) | Правится без кода, читается людьми, легко моддить |
| Сохранения | JSON в `user://saves/slot_N.json` + метаданные слота | Отлаживаемо, версионируется (`save_version`) для миграций |
| Настройки | `ConfigFile` → `user://settings.cfg` | Встроено в движок |
| Загрузка ресурсов | `ResourceLoader.load_threaded_request` для локаций, стриминг чанков мира | Без фризов на мобильных |
| UI | Встроенные Control‑узлы, общая тема, `canvas_items` + `expand` | Масштабирование под любые экраны и соотношения сторон |
| Аудио | Процедурный синтез петель при старте (`AudioStreamWAV`) + CC0‑звуки | Малый размер, уникальный звук |
| CI | GitHub Actions: импорт → тесты → экспорт APK/Linux/Windows → Release | APK скачивается со страницы Releases |

## 3. Архитектура

```
project.godot
autoload/                  ← глобальные сервисы (синглтоны)
  events.gd                шина сигналов: развязывает системы
  item_db.gd               база предметов/рецептов/лута из data/*.json
  game_state.gd            флаги мира, время, погода, журнал, репутация, навыки
  settings.gd              настройки, режим управления Android/PC, применение графики
  save_system.gd           слоты, сериализация «Saveable»-узлов
  audio_lib.gd             синтез и кэш звуков
scripts/
  core/                    утилиты: MeshKit (слияние геометрии), Rng, константы
  player/                  контроллер, камера, взаимодействие, выживание, инвентарь
  world/                   генераторы локаций, терейн, растительность, стриминг, погода, время
  interact/                двери, контейнеры, подбираемые предметы, колодец, кровать, верстак…
  npc/                     NPC: распорядок, восприятие, диалоги, торговля, ИИ‑состояния
  systems/                 крафт, строительство, квесты, радио, Гул, навыки
  ui/                      HUD, тач‑управление, инвентарь, крафт, диалоги, меню, настройки
data/                      JSON‑контент
assets/                    сторонние CC0 и собственные ассеты
docs/                      документация
tests/                     headless‑тесты систем (запускаются в CI)
```

**Принципы:**
1. **Данные отдельно от логики.** Новый предмет/рецепт/диалог/лут — правка JSON.
2. **Шина событий.** Системы не знают друг о друге: `Events.item_picked`, `Events.noise_emitted`, `Events.hum_started`…
3. **Saveable‑контракт.** Любой узел в группе `saveable` реализует `save_data() -> Dictionary` и `load_data(d)` и имеет стабильный `save_id`. Мир при загрузке восстанавливается из детерминированного seed + дельты состояния.
4. **Стабильные ID.** Каждый контейнер, дверь, предмет на земле получает ID вида `sosnovka/house_3/wardrobe`. Поэтому «взял банку из шкафа» переживает перезапуск.
5. **Абстракция ввода.** Игрок читает только `InputRouter` (вектор движения, дельта камеры, действия); источник — тач или клавиатура/мышь.
6. **Модульные локации.** Локация = генератор + данные. Стример загружает/выгружает по дистанции.

### 3.1 Оптимизация (заложено)

- Слияние геометрии здания в 1 меш на материал (`MeshKit`) → единицы draw calls на дом.
- Деревья и трава — `MultiMeshInstance3D` по чанкам с `visibility_range` (дальние чанки скрываются туманом).
- `OccluderInstance3D` для зданий; occlusion culling включён.
- Тени: 1 направленный свет с 2 сплитами, дальность зависит от пресета качества.
- NPC: обновление ИИ с частотой по дистанции (рядом — каждый кадр, далеко — раз в 0.5 с, вне чанка — «симуляция по расписанию» без физики).
- Освещение интерьеров — только фонарик/свечи игрока (атмосфера + производительность).
- Пресеты графики «Низко/Средне/Высоко» меняют масштаб рендера, тени, дальность, плотность растительности, MSAA.

## 4. Сюжет и мир

### 4.1 Событие

**3 октября, 03:17.** В Каменском районе за одну ночь пропало почти всё население — около 40 000 человек. Ни тел, ни следов борьбы: открытые двери, недоеденный ужин, машины с заглохшими двигателями на обочинах, часы, остановившиеся на 03:17. Через сутки военные оцепили район. Официально — «зона нулевого контакта». В народе — **Нулевая зона**.

Прошло 14 месяцев. Внутри остались единицы.

### 4.2 Версии произошедшего (игрок собирает сам)

| Версия | Источник в игре | Правда? |
|---|---|---|
| **Химическая авария** на комбинате «Прибой», эвакуация | Радиопередачи «Штаба ликвидации», листовки | Прикрытие |
| **Военный эксперимент** на «Объекте‑0» | Слухи выживших, документы на заправке | Частично |
| **«Зов»** — люди ушли сами, их позвали | Секта «Слышащие» в городе, дневники | Частично (описывает симптом) |
| **Проект «КАМЕРТОН»** | Подземный комплекс, терминалы, записи | Правда |

**Правда.** «Объект‑0» — сейсмоакустическая станция глубинного зондирования времён холодной войны, тайно переоборудованная под программу «КАМЕРТОН»: изучение воздействия инфразвука на поведение людей. В ночь испытания установка вошла в резонанс со старой сетью шахтных выработок и водоводов под районом. Инфразвук вызвал у людей массовую *диссоциативную фугу*: они вставали и шли — на север, к источнику. Тысячи дошли до затопленного карьера; многих военные подобрали и держат в «санатории» за периметром — без памяти. Оператор смены заблокировал установку перед тем, как сам ушёл. Установка до сих пор работает в аварийном цикле — отсюда **Гул**, который периодически накрывает зону.

Выжили те, кто не услышал: глухие, крепко спящие под лекарствами, находившиеся глубоко под землёй.

### 4.3 Главный герой

**Глеб Ланской, 36 лет, настройщик фортепиано.** Абсолютный слух, близорукость, никакой военной подготовки. Его сестра Вера — медсестра сельской амбулатории в Сосновке — пропала вместе с дочерью Алей. Через год Глеб получает открытку, отправленную *после* События, почерком Веры: «Не верь им. Мы живы. Ищи под школой». Он проходит через дыру в периметре.

Профессия — геймплейная особенность: Глеб раньше всех слышит приближение Гула (ранний сигнал на HUD) и может «прослушивать» стены и полы камертоном, находя пустоты и тайники.

### 4.4 Персонажи

| Персонаж | Где | Роль |
|---|---|---|
| **Тихон Петрович** | Сосновка | Глухой пасечник, пережил Событие, потому что не слышал. Дружелюбный, торговец, первые задания, учит выживанию. Распорядок: пасека → колодец → огород → дом. |
| **Марта «Луч»** | Заправка | Радистка, держит лагерь выживших. Голос в эфире. Нейтральна, торгует информацией. |
| **Капитан Дорохов** | Военный объект | Остатки гарнизона, получил приказ «зачистить следы». Враждебен, но с ним можно договориться. |
| **Пастор Савелий** | Город | Лидер «Слышащих», хочет запустить установку на полную — «чтобы все ушли туда, где наши». |
| **Вера Ланская** | — | Её записки ведут через всю игру. |
| **«Шакалы»** | Трасса, промзона | Мародёры. Враждебны, реагируют на шум. |

### 4.5 Основная линия (акты)

1. **Сосновка.** Найти дом Веры, амбулаторию, понять, что «под школой» — бомбоубежище. Встретить Тихона. Получить радио.
2. **Трасса и заправка.** Связаться с Мартой, узнать о «санатории», о Дорохове.
3. **Промзона.** Документы комбината доказывают: аварии не было.
4. **Город.** «Слышащие», больница — карточки пропавших, след Али.
5. **Объект‑0.** Подземный комплекс, установка «КАМЕРТОН».

### 4.6 Финалы
- **Тишина** — заглушить установку. Гул прекращается, военные входят в зону и «чистят» её. Вера найдена, но правда похоронена.
- **Эфир** — передать данные через радиовышку. Мир узнаёт правду; зона остаётся закрытой ещё надолго; Глеб — в розыске.
- **Зов** — позволить Савелию запустить установку на полную. Тёмный финал.
- **Тихий уход** — вывести Веру и Алю через периметр, ничего не трогая. Личная победа.

Финал определяется действиями (репутация, найденные доказательства, судьба NPC), а не одним выбором в диалоге.

### 4.7 Второстепенные задания (примеры)
«Пчёлы Тихона», «Мел на дверях» (выяснить, кто оставляет знаки), «Сигнал SOS на 101.3», «Машина почтальона», «Последний урок» (класс в школе, где дети писали про ночь События), «Аптечный склад».

## 6. Игровые системы

### 6.1 Выживание ✅
Показатели 0–100: **сытость, вода, бодрость (усталость), сон, температура тела (°C), здоровье**.

- Сытость −~1.2/игровой час, вода −~2/ч (быстрее при беге и жаре).
- Бодрость тратится на бег/прыжки, восстанавливается при ходьбе/отдыхе; при нуле — нельзя бежать.
- Сон падает ~4/ч; при низком — затемнение по краям, медленнее бодрость. Спать — на кровати/спальнике (пропуск времени).
- Температура тела стремится к «ощущаемой» (погода + время суток + укрытие + одежда + костёр + мокрость).
- Здоровье падает только когда что‑то критично (голод/жажда/переохлаждение/кровотечение) — у игрока всегда есть время среагировать.
- Предупреждения на HUD заранее, а не в момент смерти.

### 6.2 Инвентарь ✅
Сетка ячеек (стаки), ограничение по весу (перегруз → медленнее, нет бега), категории‑фильтры, описание, иконки (процедурные по категории), выбросить/использовать/осмотреть, перетаскивание между ячейками, панель быстрого доступа (4 слота).

### 6.3 Сбор ресурсов ✅
Логичный лут по типу помещения (`data/loot.json`): кухня → еда, мастерская/гараж → инструменты и металл, амбулатория → медицина, шкаф → одежда/ткань. Рубка деревьев (нужен топор), разбор хлама на металлолом, колодец/ручей — вода (сырая, нужно кипятить), сбор ягод и грибов в лесу.

### 6.4 Крафтинг ✅
Рецепты из `data/recipes.json`, используют реальные предметы. Рецепты открываются: найденные записки/чертежи, навык, разговоры с NPC. Станции: руки, верстак, костёр.

### 6.5 Убежище ✅
Любое здание можно объявить убежищем (ключ/вход). В радиусе убежища ставятся: спальник/кровать, ящик‑хранилище, верстак, костровая чаша, свечи/лампа, баррикада на дверь, бочка для дождевой воды. Объекты улучшаемы (ящик → большой ящик), сохраняются.

### 6.6 NPC ✅ (Тихон) 🟡 (мародёры)
Распорядок по игровому времени, навигация по путевым точкам, восприятие (зрение + слух шума), память о взаимодействиях (флаги), диалоги из JSON с условиями, торговля по ценности предметов, задания. Мародёры: патруль → настороженность → преследование/бегство.

### 6.7 Погода и время ✅
Цикл 24 ч (1 игровые сутки ≈ 48 минут реального времени, настраивается). Погода: ясно, облачно, туман, дождь, гроза, снег (поздняя осень — климат допускает). Влияет на видимость, туман, температуру, мокрость, звук.

### 6.8 Транспорт ✅
Заброшенные машины: осмотр (состояние колёс, аккумулятора, бака, свечей), обыск багажника, ремонт компонентов деталями, заправка канистрой. Одна машина в посёлке может быть восстановлена и используется для езды (VehicleBody3D). Большинство — доноры деталей.

### 6.9 Бой 🟡
Оружие как предметы (нож, монтировка, топор, самодельное копьё; огнестрел — редкость, ⏳), экипировка в руки, ограниченные патроны/прочность. Главное — избегать: шум, скрытность, приседание, обход. Враги реагируют на звук (`Events.noise_emitted`).

## 9. Управление
- **Android:** левый виртуальный джойстик (плавающий), свайп правой половиной экрана — камера, кнопки: действие, прыжок, бег (переключатель), присед, инвентарь, фонарик, быстрые слоты.
- **PC:** WASD, мышь, E — действие, Space, Shift, C/Ctrl, Tab/I — инвентарь, F — фонарик, 1–4 — быстрые слоты, Esc — пауза, M — карта, R — радио, J — журнал, Q — камертон.
- Режим переключается в настройках; тач‑интерфейс скрывается в режиме PC. При первом запуске режим определяется платформой.

## 11. Проверка качества

- **Автотесты** (`tests/test_runner.gd`, 88 проверок) запускаются в CI перед каждой сборкой: компиляция всех скриптов, целостность данных, инвентарь, крафт, постройка мира, сохранение/загрузка с восстановлением мира, каждый экран интерфейса, диалог и обмен, ходьба от сенсорного джойстика, двери, Гул, сон, костёр и готовка, езда на «Ниве», радио, смерть, переходы «меню → игра → меню → загрузка». Сборка падает при любой ошибке скрипта.
- **Контрольные скриншоты** (`tests/screenshots.tscn`) рендерятся программным Vulkan (lavapipe) — тот же мобильный рендерер, что и на телефоне.
- **Не проверено автоматически:** производительность и нагрев на реальных Android‑устройствах, удобство сенсорного управления — нужен плейтест.
